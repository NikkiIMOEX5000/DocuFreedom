## Technology

- Python and PySide6 / Qt for the application and interface.
- PyMuPDF / MuPDF for document rendering and PDF operations.
- Apple Vision and PyObjC for on-device OCR and macOS integration.
- Ghostscript for archival and print-oriented PDF export.
- pikepdf / qpdf for linearization and PDF/A checks.
- pyHanko and cryptography for local certificate signatures.
- Pillow, pillow-heif, NumPy, python-docx, openpyxl, and python-pptx for images and document formats.

## Identity and design

DocuFreedom is published by **dna.apps**. The dog mascot was created from the project owner's dog photo with the built-in image generation tool and simplified for small app-icon sizes. The private reference photograph is not included in this repository.

The requested visual direction was inspired by [Drinkit](https://drinkit.ru/): cobalt accents, rounded controls, and clear light surfaces. DocuFreedom uses its own mascot and interface, and is not affiliated with Drinkit.

The PDF tool coverage was informed by [PDF24 Creator](https://tools.pdf24.org/en/creator); no PDF24 code, branding, or Windows printer driver is included.
