# Security

DocuFreedom processes documents locally. Treat files from untrusted sources with care and keep the application and macOS updated.

For a potential vulnerability, use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, open an issue asking for a private reporting channel without publishing exploit details or affected documents.

Do not post private documents, keys, P12/PFX files, passwords, or personal information in public issues. Use a minimal synthetic reproduction whenever possible.

Current scope: desktop document parsing, local file operations, network access in the explicit webpage conversion tool, and packaging. The project does not operate an online document service.
